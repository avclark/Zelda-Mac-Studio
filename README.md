# Zelda Mac Studio

Native macOS environment, mod and snapshot manager under development. Requires macOS 14 and Xcode 16.2 or compatible Swift toolchain. No game content or keys are supplied.

Build and test: `swift test` and `swift build`. Xcode app packaging and full workflow instructions will be added with the UI milestone.

All development tests use generated synthetic files. Real game launch is blocked pending a clean verified game image and a verified isolated runtime integration.
